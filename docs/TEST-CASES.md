# 手動テストケース台帳（仕様書 12.6）

**自動テストでは守れないものだけを載せます。**

いま自動テストは 647 件あり（`scripts/check.mjs`）、権限判定・セキュリティ
ルール・容量・連番・共有リンク・画面の組み立ては、そちらが見ています。
**同じものをここに書き写すと、数だけ増えて何も守りません。**

載せるのは次のどれかに当たるものだけです。

- **人の目や耳が要る**（音が鳴る・見た目が崩れていない）
- **実物のメールや外部サービスが要る**（確認メール・Google 連携）
- **配信先でしか起きない**（キャッシュ・索引・クラウド側の権限）
- **時間がかかる**（30 日後の自動削除）

---

## 使い方

1. **検証環境**で行います（仕様書 12.2）。本番では行いません。
2. 実施したら、その行の「最終実施」を `YYYY-MM-DD` に書き換えます。
   まだ一度もやっていないものは `未実施` のままにします。
3. 期待と違ったら、**その場で直さずに記録**してください。何が起きたかを
   残すほうが、直した記憶より確かです。

> **この台帳は `test/domain/manual_test_cases_test.dart` が見張っています。**
> ID の重複、空欄、実在しない仕様の節・テストファイルへの参照があると
> 落ちます。**書き写した注意書きではなく、数えられる形にするため**です
> （[AUDIT-CHECKLIST.md](AUDIT-CHECKLIST.md)「注意書きを、仕組みと数えない」）。
