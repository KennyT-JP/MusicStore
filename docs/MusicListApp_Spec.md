# 音楽リスト共有アプリ 仕様書（ドラフト v0.1）

作成日：2026-08-04
ステータス：要件整理中のドラフト。今後の対話で追記・修正していきます。

---

## 1. 概要・目的

メンバーが個々に録音した音源や、YouTube 等で見つけた楽曲を、1 つのリストに集約して共有するためのアプリです。まず Web 版を開発し、将来的に Android / iOS アプリへの展開も見据えます。リストは複数作成でき、管理者がメンバーのアクセスを承認・管理します。

---

## 2. 対象プラットフォーム・技術スタック

| 区分 | 採用技術 | 備考 |
| --- | --- | --- |
| フロントエンド | **Flutter** | 1 つのコードで Web・Android・iOS に対応。まず Web、将来モバイル |
| バックエンド | **Firebase** | 下記の各サービスを利用 |
| データベース | Firestore | リスト・項目・コメント・ユーザー等の情報を保存 |
| 認証 | Firebase Authentication | Google 連携／メール＋パスワード |
| ファイル保存 | Firebase Storage（Cloud Storage） | 音源・動画などのファイル本体を保存 |
| プッシュ通知 | Firebase Cloud Messaging（FCM） | 将来のモバイル含むプッシュ通知 |
| サーバー処理 | Cloud Functions | 通知配信・重複チェック等のサーバー側処理 |
| Web 配信 | Firebase Hosting（想定） | Web 版のホスティング |

- **表示言語**：多言語対応とし、初期対応は **日本語・英語**。後から言語を追加しやすい設計にする。

## 3. アカウント・認証

### 3.1 ログイン方法
- Google アカウント連携
- メールアドレス＋パスワード
- **ログイン状態を保持**する（次回以降、自動でログインした状態を維持）
- メール＋パスワード登録者向けに、**パスワード再設定機能**（登録メールにリセット用リンクを送付）を用意

### 3.2 アカウント取得の 2 経路（両方対応）
1. **自己登録**：誰でも Google／メールでサインアップ可能。その後、リスト作成やリスト参加を申請できる。
2. **招待による登録**：サイト管理者・リスト管理者が招待 URL を発行して招く。

### 3.3 招待 URL の仕様
- 招待操作を行うと、**ワンタイムの招待 URL** が発行される。
- 管理者が任意の手段（メール等）でその URL を相手に伝え、受け取った人が URL をクリックすると参加できる。
- **有効期限あり**。初期値 **24 時間**。サイト管理者がサイト管理画面で変更可能。
- 発行時に、**対象リスト**と**付与する役割（Super User / Read Only）**をあらかじめ指定する。
- 発行できる人：**サイト管理者は誰に対しても**発行可／**リスト管理者は自分のリストへの招待のみ**発行可。

### 3.4 表示名
- 初期値は Google の表示名（またはメール名）。
- ユーザーが後から自由に変更可能。

### 3.5 退会（アカウント削除）
- ユーザーは自分のアカウントを自分で削除（退会）できる。
- 退会後も、その人が登録した項目・コメント等の**投稿・履歴は残す**。表示名は「**退会したユーザー**」と表示（元の名前は出さない）。

## 4. 権限・役割

### 4.1 権限階層
```
サイト管理者 ＞ リスト管理者 ＞ Super User ＞ Read Only
```
- 上位の役割は、下位の役割の権限を**すべて包含**する。
- 役割は**リストごとに個別**に決まる（例：あるユーザーがリスト A では Super User、リスト B では Read Only、も可能）。

### 4.2 各役割の主な権限
| 役割 | 主な権限 |
| --- | --- |
| サイト管理者 | サイト全体の全権限。全リストの項目・コメントの編集・削除、全リストの削除、権限変更、リスト作成申請の承認、各種サイト設定 |
| リスト管理者 | 自分が管理するリスト内の全権限（項目・コメントの編集・削除、リスト削除、メンバー招待・承認・役割割当・除外、容量把握 等） |
| Super User | リストへの項目追加・アップロード、コメント・返信 |
| Read Only | 閲覧のみ（全項目・全コメントの閲覧、音源再生・URL アクセス可）。追加・コメントは一切不可 |

### 4.3 権限の管理
- 各ユーザーの役割変更は、**サイト管理者・リスト管理者**が行う。
- 管理者自身もアップロード・コメントができる（上位は下位の権限を包含するため）。

### 4.4 サイト管理者の初期設定
- 最初のサイト管理者は、**システムを立ち上げた人**を初期サイト管理者として登録する。
- 以後、サイト管理者は他の人をサイト管理者に昇格できる。

## 5. リスト管理

### 5.1 リスト作成（申請制）
- 新規リストは**サイト管理者への申請制**。
- 申請に必要な情報：
  - **リスト名**（申請時に、既存の全リストと**重複チェック**を行う）
  - 概算の**登録曲数**
  - **使用者数**
  - **作成目的**
- サイト管理者が申請を確認して承認する。
- 承認されると、**申請者がそのリストのリスト管理者**になる。
- 申請は**初期ユーザーを含め、誰でも**可能。

### 5.2 既存リストへの参加（2 経路）
1. **招待 URL 経由**（3.3 参照）。
2. **参加申請**：リストの共有 URL から参加を申請する。
   - 申請者は役割を選べない（**アクセス申請のみ**）。
   - **リスト管理者が承認時に役割（Super User / Read Only）を決定**する。

### 5.3 リストの見え方・発見方法
- 全リストの一覧を公開する画面は**作らない**。
- リストは、**既存参加者から共有 URL をもらって**発見・申請する。
- 未参加者が共有 URL を開いた場合：**リスト名など最低限の情報＋「参加申請」ボタンのみ**を表示。中身（曲・コメント）は承認されるまで見えない。

### 5.4 メンバーの除外・離脱
- **リスト管理者（以上）**は、メンバーをそのリストから外す（アクセス権を取り消す）ことができる。
- **メンバー自身**も、自分からリストを抜けることができる。
- 外された／抜けた後も、その人の投稿・履歴は残す。表示名は「**退会したユーザー**」と表示。

### 5.5 リスト削除
- **リスト管理者**は自分のリストを削除できる。
- **サイト管理者**は全リストに対して全権限を持つ（どのリストでも削除可）。
- リストを削除すると、そのリストのファイル・コメントも**すべて削除**される。

### 5.6 管理者不在時の扱い
- リスト管理者が 1 人だけの状態でその人が退会した場合、そのリストは**管理者不在のまま保持**する。
- **サイト管理者が新しいリスト管理者を指名する**まで、その状態を維持する。
- サイト管理画面で「管理者不在のリスト」を確認・指名できるようにする。

## 6. リスト項目

### 6.1 項目の単位
- 1 項目 ＝ **音源ファイル 1 つ**、または **URL 1 つ**（両方の混在・複数登録は不可）。

### 6.2 項目が持つ情報
| 項目 | 内容 |
| --- | --- |
| 連番 | リストごとに 1 から採番。**振り直しなし**。削除時は欠番を残し、リスト上に「**削除されました**」と表示（ソフト削除） |
| 日付 | 録音日を想定（ただし厳密な意味は持たせない）。初期値は当日、**自由に変更可** |
| ファイル または URL | 音源ファイル、または URL のいずれか |
| 曲名 | **任意** |
| アーティスト名 | **任意** |
| 登録者 | **ログインユーザーを自動記録** |
| コメント | **任意**（追加・アップロード時に記入できる） |

### 6.3 編集
- 項目の**全フィールドを編集可能**（登録済みの**ファイル／URL そのものの差し替え**も含む）。
- 編集・削除できる人：**登録した本人**、および自リストのリスト管理者、サイト管理者（4.2 参照）。

### 6.4 表示・並び替え・検索
- **並び替え**：連番／日付／登録者 で並び替え可能。
- **検索**：曲名・アーティスト名で検索。曲名・アーティスト名が未記入の項目は、**ファイル名で検索**できるようにする。
- リスト上は、URL やファイル名を**そのまま表示**し、**リンク**を付ける。

## 7. ファイル・容量

### 7.1 アップロード対象
- 主に mp3・mp4 を想定するが、**ファイル種別は制限しない**（他形式も可）。
- ファイル本体は **Firebase Storage** に保存し、Firestore には「どのファイルがどこにあるか」等のメタ情報のみを持たせる。

### 7.2 容量上限（クォータ）
- **リスト単位の合計容量に上限**を設ける。
- 初期値 **1GB**。**サイト管理者がリストごとに個別**に上限を設定できる（サイト管理画面）。
- **ファイル単位の上限は設けない**。

### 7.3 容量に関する通知・挙動
- 使用量が **80% を超えたら「Notice」**、**90% を超えたら「警告」**を、**リスト管理者**へ通知する。
- 上限を超えた状態でアップロードしようとした場合：「**上限を超えました。リスト管理者にご連絡ください**」と表示し、アップロードをブロックする。

### 7.4 使用量の可視化
- **サイト管理画面**：全リストの容量使用量を表示。
- **リスト管理者**：自分のリストの容量使用量を把握できる。

---

## 8. 再生・リンクの挙動

- **アップロードされた音源・動画**：アプリ内蔵のプレーヤーは**作らない**。タップしたときに、**エンドユーザーが再生方法を選ぶ**。
  - 端末にインストールされている**別のアプリで開く**
  - **ファイルをダウンロードする**
- **URL（YouTube 等）**：リンクをタップすると**外部サイトへ遷移**する。

---

## 9. コメント

- **書き込めるのは Super User 以上**（Super User／リスト管理者／サイト管理者）。**Read Only は閲覧のみ**で、コメント・返信は一切不可。
- 項目の追加・アップロード時にコメントを記入できる（任意）。
- **返信は無制限の入れ子**（返信への返信…と、何段でもぶら下げられる）。
- **編集・削除**：
  - 自分が行ったコメントは**本人**が編集・削除できる。
  - **リスト管理者**は自分が管理するリスト内であれば、どのコメントでも編集・削除できる。
  - **サイト管理者**はどのリストのコメントでも編集・削除できる。

## 10. 通知

### 10.1 通知チャネル
- **アプリ内通知**（ベルアイコンに通知が溜まる形）
- **プッシュ通知**（FCM。将来のモバイル向け。Web でも可能な範囲で対応）

### 10.2 通知イベントと受信者
| イベント | 受信者 |
| --- | --- |
| リストに項目が追加された | 該当リストの**リスト管理者**／**サイト管理者（全リスト）** |
| コメントが付いた | 該当リストの**リスト管理者**／**サイト管理者（全リスト）**／自分の投稿・コメントにコメントが付いた**本人** |
| 容量が 80% 超（Notice）／90% 超（警告） | 該当リストの**リスト管理者** |
| リスト作成の申請があった | **サイト管理者** |
| リストへの参加申請があった | 該当リストの**リスト管理者** |
| 申請が**承認**された | **申請した本人**（※**却下時は通知しない**） |

### 10.3 通知設定（On/Off）
- 上記の**すべての通知種別を個別に On/Off** できる。
- 各種別について、**アプリ内通知／プッシュ通知**をそれぞれ個別に切り替えられる。
- さらに、**全体を一括で On/Off** するマスタースイッチを用意する。
- **初期状態は全てオン**（新規ユーザーは最初すべての通知がオン）。

## 11. 管理画面（機能まとめ）

### 11.1 サイト管理画面（サイト管理者）
- リスト作成申請の確認・承認
- 各リストの容量使用量の表示
- リストごとの容量上限の設定（初期値 1GB）
- 招待 URL の有効期限の設定（初期値 24 時間）
- 管理者不在リストの確認・リスト管理者の指名
- サイト管理者への昇格
- ユーザーの権限変更

### 11.2 リスト管理者の機能
- 自リストの容量使用量の把握
- メンバーの招待、参加申請の承認、役割の割当、メンバーの除外
- 自リスト内の項目・コメントの編集・削除
- 自リストの削除
