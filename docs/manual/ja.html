このアプリでできること

メンバーが個々に録音した音源や、動画サイトなどで見つけた曲の URL を、ひとつのリストに集めて共有できます。リストはいくつでも作れて、リストごとにメンバーと、その人にできることが決まります。

はじめて使うときの流れは、おおむね次のとおりです。

  1. アカウントを作り、メールアドレスの確認を済ませます（アカウントを作る）。
  2. リストに入ります。入り方は 2 とおりで、自分でリストの作成を申請するか、すでにあるリストに入れてもらうかのどちらかです。
  3. リストの中で、曲やコメントを足したり、その場で再生したりします。

どのリストにも自動では入れません。すでにあるリストに入るには、参加している方から 共有 URL をもらって参加を申請する（参加を申請する）か、リスト管理者から共有リンクを渡してもらいます（共有リンク）。新しくリストを作る場合は、サイト管理者の承認が要ります（リスト作成を申請する）。

ここでつまずきやすい点

全リストの一覧を見られる画面はありません。誰かに教えてもらわないと、リストは見つけられない作りになっています。中身を勝手に覗かれないようにするためです。

画面の左側（スマートフォンでは下側）に、ホーム・通知・設定 の行き先があります。サイト管理 は、サイト管理者にだけ出ます。

アカウントを作る

ログイン画面の はじめての方はこちら（新規登録） から、アカウントを作れます。作り方は 2 とおりです。

  • メールアドレスとパスワード：メールアドレス・パスワード・表示名 を入れて アカウントを作成 を押します。パスワードは 6 文字以上 です。表示名は 後から変更できます。
  • Google のアカウント：Google で続ける を押します。

メールアドレスとパスワードで登録した場合は、メールアドレスの確認が必須です。登録すると 確認メールを送りました の画面になり、届いたメールのリンクを開くまで先へ進めません。

リンクを開くと、この画面も自動で次に進みます。

リンクは別のタブや別の端末で開いてもかまいません。開いたことがアプリ側に伝わると、待っている画面はひとりでに次へ進みます。うまく進まないときは 確認を済ませたら次へ を押してください。メールが見当たらないときは 確認メールを再送する を押します。確認メールは、いま画面に出している言語で届きます。

Google のアカウントで登録した場合、この確認は要りません。Google 側で確認済みのためです。

ここでつまずきやすい点

共有リンクを受け取っていても、メールアドレスの確認が済むまでは、リストを見る／メンバーになるのどちらも選べません。先に確認を済ませてください。

ログインとパスワードの再設定

ログイン画面では、上に メールアドレス と パスワード の欄があり、または の区切りをはさんで下に Google で続ける があります。登録したときと同じ方法でログインしてください。パスワード欄の右端では パスワードを表示 と パスワードを隠す を切り替えられます。

一度ログインすると、その状態は保たれます。次に開いたときは、ログインしたままの画面が出ます。

パスワードを忘れたときは、パスワード欄の下の パスワードをお忘れですか？ を押します。メールアドレスを入れて パスワードを再設定 を押すと、再設定用のリンクが届きます。

再設定用のリンクを送信しました。メールをご確認ください。

この再設定は、メールアドレスとパスワードで登録した方のためのものです。Google のアカウントで登録した方は、パスワードを持っていないため、Google で続ける からログインしてください。

ここでつまずきやすい点

共有 URL や共有リンクをログインしていない状態で開いても、中身は何も出ません。リスト名も出ません。 先にログイン画面が出て、済ませると元の URL へ自動で戻ります。「開いても何も出ない」ときは、まずログインしてください。

Google で続ける を押しても何も起きないときは、ブラウザがログイン用のウィンドウを止めていることがあります。その場合は画面にその旨が出ますので、このサイトのポップアップを許可してから、もう一度お試しください。

ホーム（参加しているリスト）

参加しているリスト には、自分が入っているリストが並びます。それぞれの行には、リスト名・自分の役割・曲の件数が出ます。リスト管理者には、そのリストの使用容量も出ます。

まだどこにも入っていないときは、次のように出ます。

まだどのリストにも参加していません。
リストを作りたい場合は作成を申請してください。既にあるリストに入りたい場合は、参加している方から共有 URL を受け取ってください。

この画面には リスト作成を申請 と 自分の申請 の入口があります。リスト管理者以上であれば、リストの行のメニューから リンクをコピー で共有リンクをその場で作れます（共有リンク）。

リストの行に 管理者不在のリスト と出ていることがあります。そのリストのリスト管理者が抜けた状態で、サイト管理者が新しい管理者を指名するまで続きます。曲を見たり足したりすることは、これまでどおりできます。

リスト作成を申請する

新しいリストは、その場では作れません。申請して、サイト管理者に承認してもらう必要があります。ホームの リスト作成を申請 から申請します。誰でも申請できます。

申請には次の 4 つを入れます。

  • リスト名 — 既にあるリストと同じ名前は使えません
  • 概算の登録曲数
  • 使用者数
  • 作成目的

送ると、次のように出ます。

申請しました。
サイト管理者が確認して承認するまでお待ちください。

承認されると、申請した方がそのリストのリスト管理者になります。 リストはホームに現れ、メンバーを呼んだり、容量を確かめたりできるようになります。すでに使われている名前や、他の方が申請中の名前は使えず、その旨が出ます。

ここでつまずきやすい点

リスト名は申請のときに決まり、あとから変える画面はありません。名前は最初によく考えて入れてください。

自分の申請を確認する

ホームの 自分の申請 から、自分が出した申請の状態を確認できます。リスト作成の申請と、自分の参加申請 の両方が並びます。状態は 申請中・承認済み・却下済み のいずれかです。まだ何も出していなければ まだ申請はありません。 と出ます。

承認済みのものは 開く や リストを開く から、そのままリストへ行けます。

ここでつまずきやすい点

却下されても通知は届きません。 隠すためではなく、わざわざお知らせしないためです。返事が来ないと感じたら、この画面を見てください。「却下済み」であれば、そこで分かります。

却下されたあとは もう一度申請する から出し直せます。回数の制限はありません。 却下の理由は入力されないため、画面には出ません。

リストの中身

リストを開くと、登録された曲が並びます。各行には連番・日付・曲名・アーティスト名・登録者が出ます。曲名やアーティスト名が入っていない曲は、ファイル名や URL がそのまま出ます。

並び替え・検索・削除済みの表示

  • 並び替え — 連番・日付・登録者 のいずれかで並べ替えられます。
  • 検索 — 曲名・アーティスト名・ファイル名で検索 と出ている欄に入れて絞り込みます。見つからないときは 該当する項目が見つかりませんでした。 と出ます。
  • 削除済みも表示 — 削除された曲を出すかどうかを切り替えます。

削除された曲は、連番の位置に 削除されました とだけ出ます。曲名・アーティスト名・ファイル名・URL は出ません。

ここでつまずきやすい点

連番は振り直しません。 曲を削除しても、あとの曲の番号は繰り上がらず、その番号は欠番のまま残ります。番号が飛んでいるのは不具合ではありません。削除済みも表示 を切ると番号だけが飛んで見えるので、理由を知りたいときは表示に戻してください。

削除された曲は検索に出ません。 検索は「いまある曲を探す」ためのものとしているためです。

削除済みも表示 の切り替えは、この画面を開いている間だけ効きます。画面を開き直すと「表示する」に戻ります。

この画面から行ける先

右下の 追加 から曲を足せます（Super User 以上）。まだ 1 曲もないときは まだ項目がありません。 と、追加のしかたの案内が出ます。各行の 詳細 から、その曲の詳しい画面へ行けます。

画面のメニューには このリストから抜ける があります。役割にかかわらず、そのリストのメンバー全員に出ます。 リスト管理者以上には、これに加えて メンバー管理・参加申請・リスト設定 が出ます。

抜けた方や退会した方の名前は、退会したユーザー と出ます。その方が登録した曲やコメントはそのまま残ります。

曲の詳細とコメント

曲の詳細では、曲名・アーティスト名・日付・登録者・ファイルまたは URL と、その曲に付いたコメントがまとめて出ます。

アップロードされた音源や動画は、この画面から別のアプリで開いたり、ダウンロードしたりできます。URL の曲は、リンクから外部のサイトへ移ります。

コメント

コメント の欄では、コメントを書く から書き込めます。ほかの方のコメントには 返信 ができ、返信への返信も、何段でもぶら下げられます。 まだ何も書かれていないときは まだコメントはありません。 と出ます。

書けるのは Super User 以上です。Read Only の方はコメントも返信もできません（役割でできること）。自分が書いたコメントは、自分で 編集・削除 できます。リスト管理者以上は、そのリストのどのコメントでも編集・削除できます。削除されたコメントは 削除されました と出ます。

編集・削除・復元

編集 と 削除 は、その曲を登録した本人と、リスト管理者以上に出ます。削除するときは、ファイルが何日間保持されるかが画面に出ます。削除済みの曲には、リスト管理者以上に 復元 が出て、{date} まではリスト管理者が復元できます。 という形でいつまで戻せるかが出ます（容量と、削除したときの扱い）。

リスト管理者以上は、この曲のリンクをコピー から、その曲を指す共有リンクを作れます（共有リンク）。

曲を追加する・編集する

リストの 追加 から、曲を登録します。画面の上にタブがあり、ファイル と URL を切り替えます。1 つの曲に登録できるのは、ファイル 1 つか URL 1 つのどちらかだけで、両方は登録できません。

  • ファイル のタブ — ファイルを選択 で選びます。選ぶと、ファイル名とサイズ、そのリストの 残り {remaining} が出ます。
  • URL のタブ — URL の欄に入れます。

下の 日付・曲名（任意）・アーティスト名（任意）・コメント（任意） は、どちらのタブでも共通です。タブを切り替えても、入れた内容はそのまま残ります。日付は当日が初めから入っていて、自由に変えられます。日付は年月日だけの値で、時刻も時差も持ちません。 どの国から見ても、入れた方が入れたとおりの日付が出ます。

ファイルか URL が揃うまで、保存 は押せません。何が足りないかは、ボタンのそばに ファイルを選択してください または URL を入力してください と出ます。

アップロードの進み方

ファイルは先にアップロードし、それが終わってから曲が作られます。 途中は アップロード中… {percent}% と進み具合が出て、アップロードを中止 で止められます。

アップロードに失敗しました。もう一度お試しください。

通信が切れた、ブラウザを閉じた、途中で止めた、といった場合、曲は作られません。連番も使われません。 中途半端な曲が一覧に残らないようにするためです。途中から再開する仕組みはないので、はじめからやり直してください。保存に失敗しても画面は閉じないので、入れた内容は残ります。

そのリストの容量が上限に達していると、次のように出てアップロードは始まりません（容量と、削除したときの扱い）。

上限を超えました。リスト管理者にご連絡ください。

編集するとき

登録済みの曲は、詳細の 編集 から同じ画面で直せます。曲名・アーティスト名・日付・コメントは変更して保存できます。

いまはできないこと

登録済みのファイルを別のファイルに差し替えることは、まだできません。 編集画面で新しいファイルを選ぶと、次のように出て保存されません。

ファイルの差し替えはまだ実装されていません。曲名・アーティスト名・日付の変更は保存できます。

音源そのものを入れ替えたいときは、いまのところ、新しく曲を追加して古いほうを削除してください。連番は新しく振られ、古い番号は欠番として残ります。

自分が編集している間に、ほかの方が同じ曲を更新していた場合は、上書きせずに保存を止めます。

ほかの方がこの項目を更新しました。最新の内容を読み込み直してください。

読み込み直す を押して最新の内容を出してから、もう一度直してください。

再生する

曲の一覧では、各行の左にある操作でその場で鳴らせます。ボタンは、いまの状態によって変わります。

いまの状態出るボタン
止まっている再生
鳴っている一時停止・停止
一時停止している再生・停止

停止 は止めて先頭に戻します。次に 再生 を押すと頭から始まります。一時停止 はその位置で止めるので、次に押すと続きから鳴ります。

別の曲の 再生 を押すと、鳴っていたほうは止まります。2 曲が同時に鳴ることはありません。 最後まで鳴り終わると、停止したのと同じ状態に戻ります。

ここでつまずきやすい点

再生のボタンは、音として鳴らせるファイルにだけ出ます。 URL の曲（動画サイトなど）はここでは鳴らせないので、詳細からそのサイトを開いてください。ファイルの種類は登録時に制限していないため、画像や書類なども登録できますが、それらにも再生のボタンは出ません。

鳴らせなかったときは 再生できませんでした。もう一度お試しください。 と出ます。

ブラウザからの音源のダウンロードについて

Web ブラウザからの音源のダウンロードを、今後終了します。 Android アプリの公開に合わせて実施します。

これまでどおり、ブラウザでそのまま再生できます。 楽譜やその他のファイルは、これまでどおりダウンロードできます。

端末に保存してオフラインで聴く機能は、iOS / Android アプリでご利用いただけます（プレミアムの機能です）。アプリでは、曲ごとに 端末に保存 を押すか、リストのメニューから このリストを端末に保存 を選ぶと、インターネットに繋がっていなくても聴けるようになります。保存したものは ダウンロード済み から確認でき、いつでも端末から削除できます。削除しても、曲もリストも消えません。

端末に保存した音源は、30 日に一度はインターネットに接続してください。 接続がないまま 30 日を過ぎると、オフラインでの再生が止まります。そのときも端末のファイルは消えません——一度インターネットに接続すれば、また聴けるようになります。止まる前には ダウンロード済み の画面に残り日数が出ます。

共有リンク

共有リンクは、リストや曲を人に見せるための URL です。リスト管理者以上が作れます。

渡す側

作れる場所は 3 か所あり、どれを使っても同じ 1 本のリンクになります。

  • ホームのリストの行のメニューの リンクをコピー — 押すとその場でクリップボードに入り、リンクをコピーしました。 と出ます。
  • メンバー管理 の 共有リンクを作る — 作った URL が画面に出ます。取り消しもここから行います。
  • 曲の詳細の この曲のリンクをコピー — その曲を指すリンクです。開くとその曲が出ます。

作ったリンクには、必ず次の但し書きが添えられています。

有効期限はありません。何人でも、何度でも使えます。止めるときは取り消してください。
ここでつまずきやすい点

共有リンクには期限がありません。何人でも、何度でも使えます。 一度配ったリンクは、渡した相手からさらに転送されれば、そのまま広がります。止める手段は取り消しだけです。 渡す相手は、その前提で選んでください。

取り消すには メンバー管理 の リンクを取り消す を使います。取り消すと、そのリンクからは参加も閲覧もできなくなります。ただしすでに入った方・見ている方はそのまま残ります。 その方を外すには、メンバー管理から行ってください（メンバー管理）。

受け取る側

リンクを開くと リンクが共有されました の画面が出て、どちらかを選んでください。あとから変えられます。 と案内されます。選べるのは次の 2 つです。

選ぶもの何が起きるか
リストのメンバーになる メンバーになります。曲やコメントを追加できます。メンバー一覧に名前が出て、曲が追加されると通知が届きます。
リストのメンバーにならずに見る メンバーにはなりません。曲の一覧を見て、音を聴くことはできます。メンバー一覧には出ず、通知も届きません。書き込みもできません。
ここでつまずきやすい点

リストのメンバーになる を選ぶと Super User になります。 その場で曲もコメントも足せる状態です。見るだけでよい方のために、もう一方の選択肢があります。

どちらを選んでも、ログインとメールアドレスの確認は必要です。 誰が中身を見ているか分からない状態にしないためです。ログインしていなければ、先にログイン画面が出て、済ませるとこの選択画面へ自動で戻ります。

リストのメンバーにならずに見る を選んだあとでメンバーになりたくなったときは、同じリンクをもう一度開いてください。 この選択画面がまた出ます。

リンクが使えないときは、理由によって出る文言が違います。次に取るべき行動が変わるためです。

このリンクは取り消されています。共有した方に新しいリンクを依頼してください。
リンクが見つかりません。URL をご確認ください。

参加を申請する

共有リンクを持っていなくても、リストの 共有 URL があれば参加を申請できます。共有 URL は、そのリストに参加している方から教えてもらいます。

まだ入っていないリストの共有 URL を開くと、リスト名など最低限の情報と 参加を申請 のボタンだけが出ます。

このリストの中身は、参加が承認されるまで表示されません。

押すと申請が送られます。

参加を申請しました。承認されるまでお待ちください。

申請する側は役割を選べません。 リスト管理者が承認するときに 承認する役割を選んでください と出て、Super User か Read Only のどちらで受け入れるかを決めます。

ここでつまずきやすい点

却下されても通知は届きません。 自分の申請 を見れば 却下済み と分かります（自分の申請を確認する）。却下されたあとは、何度でも出し直せます。

共有 URL（参加を申請するもの）と、共有リンク（開いてその場で入るもの）は別のものです。共有リンクは /s/ から始まる URL で、開くと リンクが共有されました の選択画面が出ます。

一度リストを抜けた方や、外された方も、あらためて申請できます。外された方と自分から抜けた方を区別する仕組みはありません。

メンバー管理

メンバー管理 は、リスト管理者以上に出ます。リストのメニューから開きます。

役割の変更と除外

見出しは メンバー（{count}） の形で、いま何人いるかが出ます。各メンバーのメニューから 役割を変更：{role} で役割を変えられます。リストから外す を選ぶと、次のように確認が出ます。

このメンバーをリストから外します。

自分自身をここから外すことはできません。自分が抜けるときは、リストのメニューの このリストから抜ける を使ってください。

この画面にある 2 種類の URL

  • 共有 URL — この URL を渡すと、受け取った人は参加を申請できます。中身は承認するまで見えません。 承認する手間はかかりますが、誰を入れるかを都度決められます。
  • 共有リンクを作る — 開いた方がその場で入れるリンクです。承認は要りません。止めるときは リンクを取り消す を押します（共有リンク）。

リスト設定 は、リスト管理者以上に出ます。ここでできるのは、容量の確認とリストの削除です。

リストの削除

リストを削除すると、そのリストのファイル・コメントもすべて削除されます。この操作は取り消せません。

リスト名を変える画面はありません。名前は作成を申請したときのまま変わりません。

役割でできること

容量と、削除したときの扱い

容量の上限はリストごとに決まっています。初期値は 1GB で、リストごとの上限はサイト管理者が変えられます。ファイル 1 つあたりの上限はありません。

使用量はリスト管理者以上に見えます。ホームのリストの行と、リスト設定 の 使用容量 です。上限の 80% を超えると 容量が 80% を超えました、90% を超えると 容量が 90% を超えました の通知がリスト管理者に届きます。

上限に達すると、それ以降のアップロードは始まりません。上限を超えました。リスト管理者にご連絡ください。 と出ますので、リスト管理者からサイト管理者に上限の引き上げを依頼してください。

曲を削除したとき

ここでつまずきやすい点

曲を削除しても、ファイルはすぐには消えません。初期値で 30 日間そのまま保持され、その間は容量を消費し続けます。 上限に近いリストで削除しても、すぐには空きが増えないのはこのためです。

この猶予期間があるのは、間違えて消したものを戻せるようにするためです。この期間内であれば、リスト管理者以上が 復元 できます。 曲の詳細に {date} まではリスト管理者が復元できます。 と、いつまで戻せるかが出ます。

期間を過ぎるとファイルは完全に消え、そのぶん使用容量が減ります。ここまで来ると、もう戻せません。保持日数はサイト管理者が変えられます。

削除しても、一覧上の連番は残ります。連番は振り直さないため、削除したところは欠番になります（リストの中身）。

アップロードの途中で通信が切れたり、ブラウザを閉じたりした場合、曲は作られず、行き場を失ったファイルだけが残ることがあります。これは自動で片付けられ、容量も戻ります。

なお、リストそのものを削除した場合は猶予期間がありません。ファイルもコメントもすべて消え、元には戻せません（リスト設定）。

退会について

退会しても、登録した項目やコメントは残ります。表示名は「退会したユーザー」になります。
この操作は取り消せません。
ここでつまずきやすい点

退会しても、その方が登録した曲やコメントはリストに残ります。 消えるのはアカウントで、投稿は残ります。名前のところだけが 退会したユーザー に変わり、元の名前は出なくなります。コメントは前後のつながりで読むものなので、抜けると会話が読めなくなるためです。

ひとつのリストだけをやめたいのであれば、退会ではなく、そのリストの このリストから抜ける をお使いください（リストの中身）。

自分がただ 1 人のサイト管理者である場合、退会はできません。次のように出ますので、先に別の方をサイト管理者にしてください。

あなたは現在ただ 1 人のサイト管理者です。先に別の方をサイト管理者に指名してください。

サイト管理

サイト管理 はサイト管理者にだけ出ます。 ほかの方には、この行き先そのものが出ません。中は 4 つに分かれています。

リスト作成申請

リスト作成申請 に、保留中の申請が並びます。申請者・登録曲数・使用者数・作成目的 を見て、承認 か 却下 を選びます。承認すると、申請した方がそのリストのリスト管理者になります。 保留中のものがなければ 保留中の申請はありません。 と出ます。

リストと容量

リストと容量 に、すべてのリストの使用量と上限が並びます。容量上限を変更 から、リストごとの上限を MB 単位で入れ直せます。

管理者不在のリスト には、リスト管理者がいなくなったリストが集まります。リスト管理者を指名 から、新しい管理者を決めてください。この状態は、指名するまで続きます。

ユーザー管理

ユーザー管理 には、全員が並びます。サイト管理者 {admins} 人 / 全 {total} 人 という形で人数が出ます。各行のメニューからできることは次のとおりです。

  • ユーザーを追加 — メールアドレス・表示名・パスワードを決めて作ります。サイト管理者がパスワードを決めます。お渡ししたあとで、ご本人に変更していただいてください。 この経路で作った方は、メールアドレスの確認が済んだ扱いになります。
  • サイト管理者にする / 管理者から外す — 反映には本人の再ログインが必要です。その旨が画面に出ます。
  • リストに追加 — その方をリストのメンバーに加えます。加えるときは 追加：{role} で Super User か Read Only を必ず選びます。リスト管理者にはできません。すでにメンバーの方は加えられません。
  • 無効にする / 有効に戻す / 削除する — 下記のとおりです。
無効と削除の違い

無効は戻せます。削除は戻せません。迷ったら無効にしてください。

無効にする — ログインできなくなり、参加中のリストからも外れます。登録した曲・音源ファイル・コメントは残ります。あとから 有効に戻す で戻せますが、参加していたリストには戻りません。 必要であれば、あらためてご案内ください。無効になっている方には 無効 と出ます。

削除する — アカウントと、その方が登録した曲・音源ファイルを消します。書かれたコメントは残り、表示名が 退会したユーザー になります。 バックアップは取っていないため、元に戻せません。

自分自身に対しては、無効化も削除も行えません。自分をやめるときは 設定 の 退会する をお使いください。また、ただ 1 人のサイト管理者を降格・削除することもできません。

サイト設定

  • 新規リストの容量上限 — 初期値 1024（1GB）。既存リストの上限は「リストと容量」から変更します。
  • 削除ファイルの保持日数 — 初期値 30。この期間はリスト管理者が復元でき、容量も消費し続けます。

共有リンクに期限はないため、期限の設定はありません（共有リンク）。
