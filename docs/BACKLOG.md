## 高

### 利用者向けマニュアルの作成

**現状：存在しません。** `README.md` と `docs/SETUP.md` は開発者・運用者向けです。

必要な理由：本アプリは**画面を見ただけでは推測できない業務ルール**を多数持ちます。

- リスト作成は申請 → サイト管理者の承認が要る（仕様 5.1）
- 参加も申請または共有リンクが要る（3.3 / 5.2）
- 共有リンクは**期限が無く、何人でも何度でも使える**。止めるには取り消す（3.3）
- 共有リンクを受け取った人は「参加する」「参加せずに見る」を選ぶ。
  **参加しても最初は Read Only**で、書けるようにするのはリスト管理者（3.3 / 5.4）
- 退会しても**投稿は残り**、表示名だけ「退会したユーザー」になる（3.5）
- 項目を削除しても**30 日は容量を消費し続ける**（6.2 / 7.3）
- 連番は**振り直さない**。削除すると欠番のまま残る（6.2）

書くときの注意（監査の観点 5 より）：

- **画面に出ている文字が正本。** 1 字単位で合わせる。文書側の言い回しを優先しない
- **実在の固有名詞を書かない。** 例示は「〇〇」「利用者A」などに置き換える
- 日本語・英語の 2 本が要る（アプリが 2 言語対応のため）
- **先に l10n のハードコード解消を終えること。** 英語版マニュアルを書いても、画面が日本語のままでは合わせようがない

### 最初の表示までの待ち時間（残り。2026-08-08 の依頼者確認より）

**「早くはなったが、まだ数秒かかる」**（依頼者の実測）。
同日の対応（フォントを起動から外す／太字を廃止／Firebase SDK の先読み）で
縮んだが、まだ残っている。

いま起動時に必ず要るものは、これだけである。

| 取りに行くもの | 圧縮後 | 減らせるか |
| --- | --- | --- |
| CanvasKit（描画部） | 約 2.2MB | **ここが最大。** 下記参照 |
| `main.dart.js`（アプリ本体） | 約 0.85MB | 分割は Flutter Web では難しい |
| Firebase SDK 5 本 | 計 数百 KB | 先読み済み。**初期化を待つ構造自体**は残る |

**手として考えられるもの（未検討・未実測）。**

1. **`runApp` を Firebase の初期化より前にする。**
   いまは `await Firebase.initializeApp()` を終えてから `runApp` している
   （`lib/main.dart`）。先に画面を出し、初期化の完了を待つ間だけ
   読み込み表示にすれば、**SDK の到着を待たずに枠が出る**。
   ただし初期化前に Firebase を触るコードが 1 つでもあると落ちるので、
   触る場所を全部数えてからでないと着手できない。
2. **CanvasKit を減らす。** Flutter が用意する `skwasm` 等の選択肢を
   実測して比べる。**版によって前提が変わるので、まず実測すること。**
3. **Service Worker で 2 回目以降を速くする。**
   初回は変わらないが、2 回目以降は体感が大きく変わる。

**測り方を先に決めること。** 開発機のブラウザ枠では描画時刻を測れず、
今回は転送量と読み込み順で判断した。依頼者の開発者ツールでの実測が
唯一の当てになる数字だった。**「速くなったはず」で終わらせない。**

### 読み込み中に □（豆腐）が一瞬見える

**2026-08-08 の依頼者確認で判明。** 日本語フォントを最初の描画の
待ち時間から外した副作用。読み終わるまでの一瞬、端末側のフォントに
無い字が □ で描かれることがある。

**表示が壊れるわけではなく、フォントが届いた時点で直る。**
待ち時間を縮める効果のほうが大きいと判断して、いまは受け入れている。

消したい場合の手：

- **読み込み中は文字を出さない。** フォントが届くまでアプリ全体を
  読み込み表示にする。**それでは元に戻る**（待ち時間が復活する）ので、
  最初の 1 画面だけに限るなどの工夫が要る
- **よく使う字だけの小さなフォントを先に読む。** 全体を待たずに
  かなと常用漢字だけ先に当てる。ただし**範囲外の字は □ のままになる**
  ので、表示名や曲名に珍しい漢字が入ると直らない
- 端末のフォントを明示的に指定する（`fontFamilyFallback`）。
  □ が出るのは端末に字が無いときなので、効くかどうかは環境による

**どれも「一瞬の見た目」と「数秒の待ち時間」の取引になる。**
どちらを取るかは依頼者の判断。

### 定期実行の関数の確認（`purgeDeletedFiles`）

**自動テストの対象外です。** 61 件の統合テストは定期実行の関数を
一度も呼びません。**元から確かめる項目が無かった**ものであり、
2026-08-08 に減らしたわけではありません。

このため `functions/run-integration.mjs` は **Pub/Sub エミュレータを
起動しません**。起動しても読み込まれるだけで何も確かめられないうえ、
**Pub/Sub エミュレータだけが実行のたびに別の窓を開く**ためです
（Windows で実測）。

手で確かめるときは `npm run serve` を使ってください。そちらには
Pub/Sub が入っており、関数が読み込まれます。

確かめる価値は小さくありません。**消したファイルは戻せない**からです。
やるなら次の 2 つを見ます。

- 猶予期間（既定 30 日）を過ぎた項目のファイルだけが消えること
- 孤児ファイル（既定 24 時間）の判定が、生きているファイルを巻き込まないこと

`functions/src/domain/paths.ts` の判定自体は `npm test` の 75 件で
守られています。足りないのは**通しで動かしたときの確認**です。

## 低

### 古いブラウザに残ったアイコンフォントの手当て

**2026-08-07 に判明した不具合の残りです。** 経緯は [DEVLOG.md](DEVLOG.md)。

`firebase.json` でフォントを `immutable`（1 年、取り直さない）にしていたため、
**一度でも開いたことがあるブラウザには古いアイコンフォントが残ります。**
設定は直しましたが、**すでに配られた指定は取り消せません。**

- 該当する方には **F12 → Application → Clear site data** を一度お願いする
- 利用者が多く周知が難しければ、アイコンフォントのファイル名にビルドごとの印を
  付けて古い指定を無効化する（`flutter build web` の出力に手を入れる必要があります）

**利用者がごく少数のうちは、周知で足ります。** 増える前に判断してください。

### 日本語の名前が五十音順に並ばない

Dart の文字列比較は文字コード順のため（佐藤 &lt; 田中 &lt; 鈴木）。
読み仮名を持たない限り解決できないため、現状は制限として受け入れています。
直すなら `users` に読み仮名を持たせる必要があります。

### Android の release 署名

`android/app/build.gradle.kts` が debug 署名鍵のままです（Flutter テンプレートの TODO）。
Android 版を配布する段階で対応してください。Web のみの現状では影響ありません。
