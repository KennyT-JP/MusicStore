## 高

### 利用者向けマニュアルの作成

**現状：存在しません。** `README.md` と `docs/SETUP.md` は開発者・運用者向けです。

必要な理由：本アプリは**画面を見ただけでは推測できない業務ルール**を多数持ちます。

- リスト作成は申請 → サイト管理者の承認が要る（仕様 5.1）
- 参加も申請または招待 URL が要る（3.3 / 5.2）
- 招待 URL は**一度しか使えず、既定 24 時間で切れる**（3.3）
- 退会しても**投稿は残り**、表示名だけ「退会したユーザー」になる（3.5）
- 項目を削除しても**30 日は容量を消費し続ける**（6.2 / 7.3）
- 連番は**振り直さない**。削除すると欠番のまま残る（6.2）

書くときの注意（監査の観点 5 より）：

- **画面に出ている文字が正本。** 1 字単位で合わせる。文書側の言い回しを優先しない
- **実在の固有名詞を書かない。** 例示は「〇〇」「利用者A」などに置き換える
- 日本語・英語の 2 本が要る（アプリが 2 言語対応のため）
- **先に l10n のハードコード解消を終えること。** 英語版マニュアルを書いても、画面が日本語のままでは合わせようがない

### 手動テストケース台帳の整備

**現状：存在しません。** 仕様 12.6 が「確認観点リストとして別途整備する」としたまま未作成です。
`docs/SETUP.md` にチェックボックスが 12 個あるだけで、ケース ID・事前条件・期待結果・実施記録がありません。

**このため、監査で手動側の網羅性を測定できませんでした。** 「自動で守る／手動で確認する」と方針を決めた以上、手動側にも数えられる形が要ります。

整備するときは、**自動テストにも ID を振って相互参照できるようにすること。** そうしないと監査のたびにゼロから数え直しになります。

## 中

### 項目編集時のファイル差し替え（仕様 6.3 / 13.4 / 14.4）

旧ファイルの猶予期間つき削除が要るため、Functions 側の対応と合わせて実装します。
`items.previousFiles` の受け口は `functions/src/scheduled/purge.ts` が**読む側だけ**用意して
ありますが、**書く処理はどこにもありません**（監査 第2回）。
クライアントからは書けないようルールで塞いであるので、実装するときは Functions 経由にしてください。

**未実装のあいだの実際の挙動：**

- 項目編集でファイルを選ぶと、その旨を表示して保存を止めます
- ただし**ファイル → URL への切り替えは通ります**。このとき旧ファイルは孤児になり、
  仕様が想定する 30 日ではなく **24 時間**（`orphanFileGraceHours`）で削除されます

### 削除済み項目の表示切替を端末に保持する（仕様 6.4）

仕様は「設定は端末側に保持し、次に開いたときも維持する」としていますが、
現状はメモリ上だけで、画面を開き直すと既定に戻ります（監査 第2回）。
`shared_preferences` 等の依存追加が要るため後回しにしています。

### 一覧で URL・ファイル名にリンクを付ける（仕様 6.4）

現状は文字列を表示するだけで、再生・ダウンロードは項目詳細から行います（監査 第2回）。

### サイト設定に `orphanFileGraceHours` を出す（仕様 13.3）

データとしては持っていますが、サイト管理画面に入力欄がなく、
初期値の 24 時間から変えられません（監査 第2回）。

### 依存パッケージの脆弱性確認

**2 回の監査でどちらも実行されていません。** `npm audit` と `flutter pub outdated` を
一度も回していないため、既知の脆弱性があるかどうかが分かりません。
「指摘 0 件」ではなく「見ていない」状態です。

### 実行時の性能実測

監査の性能に関する数値は**すべて理論値**です（コードからの積算）。
Firestore の読み取り件数・初期表示時間・Functions の実行時間は測っていません。
検証環境で 1 度は実測し、次回の比較対象にしてください。

### `firebase-functions` の版上げ

デプロイのたびに「outdated」と警告が出ますが、**互換性のない変更を含みます**。
検証環境で一通り動作を確認してから、別作業として行ってください。

## 低

### 本番環境の構築

**Firestore と Cloud Storage のロケーションは作成後に変更できません。** 決めきってから作ってください。

- 利用者が日本中心なら Firestore は `asia-northeast1`
- Cloud Storage は無料枠が `us-central1` / `us-west1` / `us-east1` にしかない（仕様 12.1）
- 費用を決めるのは保存量ではなく**ダウンロード量**

### 予算アラートの設定

自動停止を実装しない方針のため（仕様 12.1）、**これが唯一の歯止め**です。本番構築と同時に行ってください。

### 日本語の名前が五十音順に並ばない

Dart の文字列比較は文字コード順のため（佐藤 &lt; 田中 &lt; 鈴木）。
読み仮名を持たない限り解決できないため、現状は制限として受け入れています。
直すなら `users` に読み仮名を持たせる必要があります。

### Android の release 署名

`android/app/build.gradle.kts` が debug 署名鍵のままです（Flutter テンプレートの TODO）。
Android 版を配布する段階で対応してください。Web のみの現状では影響ありません。
