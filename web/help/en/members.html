Managing members

Manage members is available to list admins and above, from the list's menu.

Changing roles and removing people

The heading reads Members ({count}) and gives the current count. Each member's menu offers Change role: {role} to change their role, and Remove from list, which asks you to confirm:

This member will be removed from the list.

Their items and comments stay, but their name will be shown as "Former member". They can request to join again.

You cannot remove yourself from here. To leave a list yourself, use Leave this list in the list's own menu.

People viewing without joining

Viewing without joining lists everyone who opened a share link and chose View without becoming a member. If there is nobody, it reads No one yet.

Worth knowing

These people are not members. They do not count towards the member total, they never receive notifications about the list, and they cannot add tracks or comments. This list exists so you can still see who is looking.

The two URLs on this screen

  • Share URL — Anyone with this URL can request to join. They cannot see the contents until approved. It costs you an approval step, but you decide case by case who gets in.
  • Create a share link — whoever opens this one is in straight away, with no approval. Use Revoke link to stop it (see Share links).

Incoming requests are approved or rejected on the Join requests screen. With nothing waiting, it reads There are no pending requests.

List settings

List settings is available to list admins and above. It covers two things: storage and deleting the list.

Storage used

Storage used shows the amount used against the limit, as "used / limit". As the list fills up, a note is added:

Over 80% of the limit.
Over 90% of the limit. Ask a site administrator to raise it.
Files from deleted items are kept for a while, so deleting does not free space immediately.

Only a site admin can change the limit itself, so ask one when a list runs short (see Storage and deletion).

Deleting the list

Deleting this list also deletes all of its files and comments. This cannot be undone.

Delete list asks you to confirm once more, naming the list. There are no backups, so anything deleted is gone for good.

Worth knowing

There is no screen for renaming a list. A list keeps the name it was given when it was requested.

What each role can do

There are four roles: Site admin, List admin, Super User and Read Only. Each role includes everything the roles below it can do.

Worth knowing

Roles are set per list. The same person can be a Super User in one list and Read Only in another. Your role in a given list is shown on that list's row on Home, so check there when you are unsure.

Read Only really is read-only. Beyond not being able to add tracks, a Read Only member cannot post comments or replies at all. Actions you are not allowed to take are not shown as disabled buttons — they are not shown at all. If a button seems to be missing, check your role in that list.

Anyone who opened a share link and chose View without becoming a member has no role. They can browse and listen, but they cannot post anything and do not appear among the members (see Managing members).

Roles are changed by list admins and site admins. Neither a share link nor an approved join request ever makes someone a list admin.
