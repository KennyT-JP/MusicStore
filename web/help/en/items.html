Track details and comments

A track's own screen gathers the title, artist, Date, Added by and the file or URL, together with every comment on it.

For uploaded audio and video, this screen lets you open the file in another app or download it. For a track that is a URL, following the link takes you out to that site.

Comments

Under Comments, use Write a comment to post. You can Reply to anyone, and replies to replies nest as deeply as you like. Before anyone has posted you see There are no comments yet.

Posting requires Super User or above. Read Only members cannot comment or reply at all (see What each role can do). You can edit and delete your own comments; list admins and above can edit or delete any comment in their list. A deleted comment shows as Deleted.

Editing, deleting and restoring

Edit and Delete appear for whoever added the track, and for list admins and above. When you delete, the app tells you how many days the file will be kept. Deleted tracks offer Restore to list admins and above, along with a line reading List administrators can restore this until {date}. (see Storage and deletion).

List admins and above can also use Copy a link to this track to create a share link pointing at this one track (see Share links).

Adding and editing tracks

Add inside a list opens the add screen. Tabs at the top switch between File and URL. A track holds either one file or one URL — never both.

  • On the File tab, press Choose a file. Once chosen, the app shows the file name and size along with the list's remaining space, as in {remaining} left.
  • On the URL tab, type the address into the URL field.

The fields below — Date, Title (optional), Artist (optional) and Comment (optional) — are shared by both tabs, and switching tabs keeps whatever you have typed. The date starts as today and you can change it freely. It is a plain calendar date with no time and no time zone, so it reads the same from anywhere in the world as the person who entered it meant it.

Save stays disabled until the file or URL is there. What is missing is spelled out next to the button, as Please choose a file or Please enter a URL.

How uploading works

The file is uploaded first, and the track is only created once that finishes. Along the way you see Uploading… {percent}%, and Cancel upload stops it.

Upload failed. Please try again.

If the connection drops, the browser closes, or you cancel, no track is created and no number is used up. That keeps half-finished entries out of the list. There is no way to resume a partial upload, so start it again from the beginning. A failed save leaves the screen open, so nothing you typed is lost.

If the list has hit its storage limit, the upload never starts and you see this instead (see Storage and deletion):

Storage limit reached. Please contact the list admin.

Editing an existing track

Edit on the track's screen reopens the same form. The title, artist, date and comment can all be changed and saved.

Not available yet

Swapping an already-uploaded file for a different one is not possible yet. Choosing a new file while editing stops the save and shows this:

Replacing the file is not implemented yet. You can still change the title, artist and date.

To replace the audio itself, add the recording as a new track and delete the old one. The new track gets a new number, and the old number stays behind as a gap.

If someone else updates the same track while you are editing it, your save is stopped rather than allowed to overwrite theirs:

Someone else updated this item. Please reload the latest version.

Press Reload to pull in the current version, then make your changes again.

Playback

In the track list, the control at the left of each row plays the audio right there. Which buttons appear depends on what is happening:

Current stateButtons shown
StoppedPlay
PlayingPause and Stop
PausedPlay and Stop

Stop halts playback and rewinds to the start, so the next Play begins from the beginning. Pause holds your place, so the next Play picks up where you left off.

Pressing Play on a different track stops whatever was playing. Two tracks never play at once. When a track reaches the end, it returns to the stopped state.

Worth knowing

The play control only appears on files that can actually be played as audio. Tracks that are URLs — a video site, say — cannot be played here, so open them from the track's screen instead. File types are not restricted at upload, so images and documents can be stored too; they get no play control either.

If playback fails, the app says Could not play this. Please try again.

About downloading audio from your browser

Downloading audio from a web browser will end. This will happen when the Android app is released.

You can still play audio directly in your browser as before. Sheet music and other files can still be downloaded as before.

Saving tracks to a device and listening offline is available in the iOS and Android apps (a premium feature). In the app, press Save to this device on a track, or choose Save this list to this device from the list menu, and it plays without an internet connection. Everything you saved is listed under Downloaded, and you can remove it from the device whenever you like. Removing it does not delete the track or the list.

Audio saved on a device needs an internet connection at least once every 30 days. After 30 days without one, offline playback stops. The files stay on the device even then — connect once and you can listen again. Before it stops, the Downloaded screen shows how many days are left.
