Home: the lists you belong to

Your lists shows every list you belong to. Each row gives the list name, your role in that list, and how many tracks it holds. List admins also see how much storage the list is using.

Before you belong to anything, you will see this:

You have not joined any list yet.
To start a new list, submit a request. To join an existing one, ask a member for its share URL.

This screen is also where Request a new list and My requests live. If you are a list admin or above, the menu on a list's row offers Copy link, which creates a share link on the spot (see Share links).

A row may be tagged Lists without an admin. That means the list's admin has left, and it stays that way until a site admin appoints a new one. You can still browse and add tracks as before.

Requesting a new list

You cannot create a list outright. You submit a request and a site admin approves it. Start from Request a new list on Home. Anyone can submit a request.

A request asks for four things:

  • List name — A name already in use is not allowed
  • Estimated number of tracks
  • Expected number of users
  • Purpose

Once you send it:

Request submitted.
Please wait for a site administrator to review and approve it.

When the request is approved, you become the list admin of that list. It appears on your Home screen, and you can start inviting members and watching its storage. Names already taken — or already requested by someone else — are refused, and the app tells you so.

Worth knowing

The list name is fixed when you request it. There is no screen for renaming a list afterwards, so choose the name carefully.

Checking your requests

My requests on Home shows the state of everything you have submitted — both new-list requests and, under Your join requests, requests to join existing lists. Each one reads Pending, Approved or Rejected. If you have not submitted anything, you see You have no requests yet.

Approved entries have an Open or Open list action that takes you straight there.

Worth knowing

You are not notified when a request is rejected. Nothing is being hidden — we simply do not send a message about it. So if a request seems to have gone quiet, check this screen. A rejected request says so plainly.

After a rejection you can submit again with Request again, and there is no limit on how many times you may try. Administrators are not asked to give a reason, so no reason is shown.

Inside a list

Opening a list shows its tracks. Each row carries the number, the date, the title, the artist and who added it. Tracks with no title or artist show their file name or URL instead.

Sorting, searching and deleted tracks

  • Sort by — order the list by No., Date or Added by.
  • Search — the field reads Search by title, artist, or file name. When nothing matches you get No items matched your search.
  • Show deleted items — turn deleted tracks on and off in the list.

A deleted track keeps its place in the numbering and shows only Deleted. Its title, artist, file name and URL are not shown.

Worth knowing

Numbers are never reassigned. Deleting a track does not renumber the ones after it — that number simply stays missing. A gap in the numbering is not a bug. If you turn Show deleted items off you will see the gaps without an explanation, so turn it back on when you want to know what happened.

Deleted tracks never appear in search results. Search is meant for finding what is currently in the list.

The Show deleted items setting lasts only while the screen is open. Reopen the list and it goes back to showing them.

Where you can go from here

The Add button at the bottom right adds a track (Super User and above). While the list is empty you get There are no items yet. along with a hint about how to add one. Each row has a Details action leading to that track's own screen.

The screen menu holds Leave this list, and it is there for every member regardless of role. List admins and above also get Manage members, Join requests and List settings.

People who have left, or who have closed their account, appear as Former member. The tracks and comments they added stay where they are.
