Storage and deletion

The storage limit applies per list. It starts at 1GB, and a site admin can set a different limit for each list. There is no limit on the size of an individual file.

List admins and above can see how much is used, both on the list's row on Home and under Storage used in List settings. Passing 80% sends the list's admins a Storage passed 80% notification, and passing 90% sends Storage passed 90%.

Once the limit is reached, further uploads do not start. You get Storage limit reached. Please contact the list admin., and the list admin should ask a site admin to raise the limit.

When a track is deleted

Worth knowing

Deleting a track does not free its file right away. The file is kept for 30 days by default, and it keeps using storage the whole time. That is why deleting things in a nearly-full list does not immediately make room.

The delay exists so that mistakes can be undone. During that window, list admins and above can Restore the track. The track's screen shows exactly how long is left, as List administrators can restore this until {date}.

Once the window passes, the file is deleted for good and the storage is released. At that point there is no way back. A site admin can change how many days are allowed.

Deleting a track leaves its number in place. Numbers are never reassigned, so a deleted track leaves a permanent gap (see Inside a list).

If an upload is interrupted — the connection drops, or the browser closes — no track is created, and the orphaned file is cleaned up automatically, returning the space.

Deleting an entire list works differently: there is no grace period. Every file and comment goes at once, and none of it can be recovered (see List settings).

Notifications

Reach Notifications either from the navigation or from the bell at the top, which carries a badge with your unread count. Notifications are listed newest first, and tapping one takes you to whatever it is about. Mark all as read clears the badge. With nothing waiting, the screen reads No notifications.

What triggers a notification

NotificationWho receives it
A song was addedEvery member of that list, whatever their role
A comment was postedThe list's admins, site admins, and whoever posted the thing being commented on
Storage passed 80%The list's admins
Storage passed 90%The list's admins
A list was requestedSite admins
Someone asked to joinThe list's admins
Your request was approvedWhoever submitted the request
Worth knowing

You are never notified about your own actions. Adding a track yourself does not send you a notification about it.

Rejections are never notified. Check My requests for the outcome instead (see Checking your requests).

Added tracks are the one case decided by membership rather than role, so Read Only members get those too. In the other direction, even a site admin hears nothing about tracks in lists they have not joined.

Choosing what you receive

Open Notifications under Settings. All seven types above can be switched individually, and All notifications turns everything off at once. Everything starts switched on, and each type carries a line describing exactly when it fires.

Settings and leaving

Settings covers the following:

  • Display name — the name others see. Change it whenever you like and press Save.
  • Language — Japanese or English. This guide opens in whichever you choose.
  • Notifications — as described under Notifications.
  • Sign out
  • Withdraw from the service

Premium and coupons

Settings has a Premium section. With Premium you can:

  • Create a list without a request. Without Premium you submit a request and wait for a site admin to approve it (see Requesting a new list); with Premium you create one on the spot from Create a list.
  • Use more storage.
  • In the app, save audio to your device and listen offline (see Playback).

To go Premium, enter a coupon code. Type the code you received into the Coupon code field and press Redeem coupon. Once it is accepted, the screen shows how long your Premium lasts: Premium is active until {date}. when it is active, or You are not on Premium at the moment. when it is not.

Worth knowing

When Premium expires, the audio and lists you saved are not removed. Without Premium, everything you have already saved stays as it is. You simply cannot create a new list without submitting a request.

If a code is refused, the wording depends on why. A typo is fixed by entering it again, but a disabled or expired coupon is one to raise with whoever gave it to you.

Audio saved on this device (app)

This section appears only in the iOS and Android apps. A web browser has nowhere to save audio, so it is not shown there. Audio saved on this device shows how much is currently stored on the device. When there is nothing, it reads No audio is saved on this device. Use View downloads to reach the list of saved tracks (see Playback).

  • Download over mobile data too — off at first. When this is off, downloads run only while you are connected to Wi-Fi. Turn it on to save over mobile data as well.
  • Remove everything from this device — clears all audio saved on the device at once. Your tracks, your lists and the files you uploaded are not deleted. You can still play them online, and download them again.

Withdrawing

Your items and comments stay in the lists after you leave. Your name will be shown as "Former member".
This cannot be undone.
Worth knowing

Withdrawing does not remove the tracks and comments you added. The account goes; the posts stay. Only your name changes, to Former member, and your real name is no longer shown. Comments are kept because a conversation stops making sense when pieces of it vanish.

If you only want out of one list, do not withdraw — use Leave this list in that list instead (see Inside a list).

If you are the only site admin, you cannot withdraw. You will see the message below; appoint someone else as a site admin first.

You are currently the only site admin. Please appoint another site admin first.

Site administration

Site admin appears only for site admins — for everyone else the navigation entry is simply absent. It has five parts.

List requests

List requests holds every pending request. Weigh up the Requested by, Tracks, Expected number of users and Purpose, then choose Approve or Reject. Approving makes the requester the list admin of the new list. With nothing waiting, the screen reads There are no pending requests.

Lists and storage

Lists and storage shows every list with its usage and limit. Change storage limit sets a list's limit in MB.

Lists without an admin collects lists whose admin has gone. Use Assign a list admin to appoint a replacement — the list stays in that state until you do.

Users

Users lists everyone, with a summary in the form {admins} of {total} users are site admins. Each row's menu offers:

  • Add user — create an account with an email address, display name and password. As the screen puts it, You choose the password. Ask them to change it once you have handed it over. Accounts created this way count as already email-verified.
  • Make site admin and Remove as administrator — the change applies after that person signs in again, and the app says so.
  • Add to a list — put someone into a list directly. You must pick the role via Add as {role}, choosing Super User or Read Only; you cannot make someone a list admin this way, and existing members are refused.
  • Disable, Re-enable and Delete — see below.
Disable versus delete

Disabling can be undone. Deleting cannot. When in doubt, disable.

Disable — the person can no longer sign in and is removed from the lists they belonged to, but their tracks, audio files and comments are kept. Re-enable restores their access, though it does not put them back into their lists — invite them again if they need to be there. Disabled accounts are tagged Disabled.

Delete — removes the account along with the tracks and audio files that person added. Their comments are kept, shown as Former member. There are no backups, so this cannot be undone.

You cannot disable or delete your own account here. To close your own account, use Withdraw from the service in Settings. Nor can the only remaining site admin be demoted or deleted.

Coupons

Coupons is where you issue and manage the coupons that grant members Premium. Create one from Issue a coupon. You decide:

  • Months granted — how long the coupon's Premium lasts.
  • Number of people — how many people can use it.
  • Coupon expiry — choose No expiry or Set an expiry.
  • The code can be Generate automatically or Specify the text.

Issued coupons are listed, and each row's menu offers Disable, Change the number of people and See who used it. When there are none, it reads There are no coupons yet.

Worth knowing

A memorable code you set with Specify the text is also easier for others to guess. Always set the number of people and an expiry.

Site settings

  • Default storage limit for new lists — Default 1024 (1GB). Change existing lists from "Lists and storage".
  • Days to keep deleted files — Default 30. List administrators can restore during this period, and the space stays used.

Share links never expire, so there is no expiry setting to configure (see Share links).
