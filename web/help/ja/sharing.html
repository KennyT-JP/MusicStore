共有リンク

共有リンクは、リストや曲を人に見せるための URL です。リスト管理者以上が作れます。

渡す側

作れる場所は 3 か所あり、どれを使っても同じ 1 本のリンクになります。

  • ホームのリストの行のメニューの リンクをコピー — 押すとその場でクリップボードに入り、リンクをコピーしました。 と出ます。
  • メンバー管理 の 共有リンクを作る — 作った URL が画面に出ます。取り消しもここから行います。
  • 曲の詳細の この曲のリンクをコピー — その曲を指すリンクです。開くとその曲が出ます。

作ったリンクには、必ず次の但し書きが添えられています。

有効期限はありません。何人でも、何度でも使えます。止めるときは取り消してください。
ここでつまずきやすい点

共有リンクには期限がありません。何人でも、何度でも使えます。 一度配ったリンクは、渡した相手からさらに転送されれば、そのまま広がります。止める手段は取り消しだけです。 渡す相手は、その前提で選んでください。

取り消すには メンバー管理 の リンクを取り消す を使います。取り消すと、そのリンクからは参加も閲覧もできなくなります。ただしすでに入った方・見ている方はそのまま残ります。 その方を外すには、メンバー管理から行ってください（メンバー管理）。

受け取る側

リンクを開くと リンクが共有されました の画面が出て、どちらかを選んでください。あとから変えられます。 と案内されます。選べるのは次の 2 つです。

選ぶもの何が起きるか
リストのメンバーになる メンバーになります。曲やコメントを追加できます。メンバー一覧に名前が出て、曲が追加されると通知が届きます。
リストのメンバーにならずに見る メンバーにはなりません。曲の一覧を見て、音を聴くことはできます。メンバー一覧には出ず、通知も届きません。書き込みもできません。
ここでつまずきやすい点

リストのメンバーになる を選ぶと Super User になります。 その場で曲もコメントも足せる状態です。見るだけでよい方のために、もう一方の選択肢があります。

どちらを選んでも、ログインとメールアドレスの確認は必要です。 誰が中身を見ているか分からない状態にしないためです。ログインしていなければ、先にログイン画面が出て、済ませるとこの選択画面へ自動で戻ります。

リストのメンバーにならずに見る を選んだあとでメンバーになりたくなったときは、同じリンクをもう一度開いてください。 この選択画面がまた出ます。

リンクが使えないときは、理由によって出る文言が違います。次に取るべき行動が変わるためです。

このリンクは取り消されています。共有した方に新しいリンクを依頼してください。
リンクが見つかりません。URL をご確認ください。

参加を申請する

共有リンクを持っていなくても、リストの 共有 URL があれば参加を申請できます。共有 URL は、そのリストに参加している方から教えてもらいます。

まだ入っていないリストの共有 URL を開くと、リスト名など最低限の情報と 参加を申請 のボタンだけが出ます。

このリストの中身は、参加が承認されるまで表示されません。

押すと申請が送られます。

参加を申請しました。承認されるまでお待ちください。

申請する側は役割を選べません。 リスト管理者が承認するときに 承認する役割を選んでください と出て、Super User か Read Only のどちらで受け入れるかを決めます。

ここでつまずきやすい点

却下されても通知は届きません。 自分の申請 を見れば 却下済み と分かります（自分の申請を確認する）。却下されたあとは、何度でも出し直せます。

共有 URL（参加を申請するもの）と、共有リンク（開いてその場で入るもの）は別のものです。共有リンクは /s/ から始まる URL で、開くと リンクが共有されました の選択画面が出ます。

一度リストを抜けた方や、外された方も、あらためて申請できます。外された方と自分から抜けた方を区別する仕組みはありません。
