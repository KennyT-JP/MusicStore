リストを作る・見る

録音した音源や、見つけた曲の URL を、ひとつのリストに集めて仲間と共有するためのアプリです。

ホーム（参加しているリスト）

参加しているリスト には、自分が入っているリストが並びます。それぞれの行には、リスト名・自分の役割・曲の件数が出ます。リスト管理者には、そのリストの使用容量も出ます。

まだどこにも入っていないときは、次のように出ます。

まだどのリストにも参加していません。
リストを作りたい場合は作成を申請してください。既にあるリストに入りたい場合は、参加している方から共有 URL を受け取ってください。

この画面には リスト作成を申請 と 自分の申請 の入口があります。リスト管理者以上であれば、リストの行のメニューから リンクをコピー で共有リンクをその場で作れます（共有リンク）。

リストの行に 管理者不在のリスト と出ていることがあります。そのリストのリスト管理者が抜けた状態で、サイト管理者が新しい管理者を指名するまで続きます。曲を見たり足したりすることは、これまでどおりできます。

リスト作成を申請する

新しいリストは、その場では作れません。申請して、サイト管理者に承認してもらう必要があります。ホームの リスト作成を申請 から申請します。誰でも申請できます。

申請には次の 4 つを入れます。

  • リスト名 — 既にあるリストと同じ名前は使えません
  • 概算の登録曲数
  • 使用者数
  • 作成目的

送ると、次のように出ます。

申請しました。
サイト管理者が確認して承認するまでお待ちください。

承認されると、申請した方がそのリストのリスト管理者になります。 リストはホームに現れ、メンバーを呼んだり、容量を確かめたりできるようになります。すでに使われている名前や、他の方が申請中の名前は使えず、その旨が出ます。

ここでつまずきやすい点

リスト名は申請のときに決まり、あとから変える画面はありません。名前は最初によく考えて入れてください。

自分の申請を確認する

ホームの 自分の申請 から、自分が出した申請の状態を確認できます。リスト作成の申請と、自分の参加申請 の両方が並びます。状態は 申請中・承認済み・却下済み のいずれかです。まだ何も出していなければ まだ申請はありません。 と出ます。

承認済みのものは 開く や リストを開く から、そのままリストへ行けます。

ここでつまずきやすい点

却下されても通知は届きません。 隠すためではなく、わざわざお知らせしないためです。返事が来ないと感じたら、この画面を見てください。「却下済み」であれば、そこで分かります。

却下されたあとは もう一度申請する から出し直せます。回数の制限はありません。 却下の理由は入力されないため、画面には出ません。

リストの中身

リストを開くと、登録された曲が並びます。各行には連番・日付・曲名・アーティスト名・登録者が出ます。曲名やアーティスト名が入っていない曲は、ファイル名や URL がそのまま出ます。

並び替え・検索・削除済みの表示

  • 並び替え — 連番・日付・登録者 のいずれかで並べ替えられます。
  • 検索 — 曲名・アーティスト名・ファイル名で検索 と出ている欄に入れて絞り込みます。見つからないときは 該当する項目が見つかりませんでした。 と出ます。
  • 削除済みも表示 — 削除された曲を出すかどうかを切り替えます。

削除された曲は、連番の位置に 削除されました とだけ出ます。曲名・アーティスト名・ファイル名・URL は出ません。

ここでつまずきやすい点

連番は振り直しません。 曲を削除しても、あとの曲の番号は繰り上がらず、その番号は欠番のまま残ります。番号が飛んでいるのは不具合ではありません。削除済みも表示 を切ると番号だけが飛んで見えるので、理由を知りたいときは表示に戻してください。

削除された曲は検索に出ません。 検索は「いまある曲を探す」ためのものとしているためです。

削除済みも表示 の切り替えは、この画面を開いている間だけ効きます。画面を開き直すと「表示する」に戻ります。

この画面から行ける先

右下の 追加 から曲を足せます（Super User 以上）。まだ 1 曲もないときは まだ項目がありません。 と、追加のしかたの案内が出ます。各行の 詳細 から、その曲の詳しい画面へ行けます。

画面のメニューには このリストから抜ける があります。役割にかかわらず、そのリストのメンバー全員に出ます。 リスト管理者以上には、これに加えて メンバー管理・参加申請・リスト設定 が出ます。

抜けた方や退会した方の名前は、退会したユーザー と出ます。その方が登録した曲やコメントはそのまま残ります。
